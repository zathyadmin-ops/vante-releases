# Vante — instaladores

Assistente de inteligência artificial para Windows, da **AEVUM**.

**Baixar:** abra [Releases](https://github.com/zathyadmin-ops/vante-releases/releases) e baixe o `Vante-Setup.exe` da versão mais recente.

- O Vante instalado verifica atualizações aqui (dá para desligar em **Ajustes → Sistema**).
- Cada versão traz o **SHA-256** do instalador; o Vante só instala uma atualização se o arquivo conferir.
- Este repositório contém **apenas os instaladores** — o código-fonte não é público.

> **Versão em desenvolvimento.** Os Termos de Uso e a Política de Privacidade (dentro do app) ainda são
> preliminares e **não estão legalizados**; os serviços do Vante seguem funcionando normalmente.
> O instalador ainda não tem assinatura digital, então o Windows pode mostrar o aviso
> "O Windows protegeu o computador" — clique em **Mais informações → Executar assim mesmo**.
